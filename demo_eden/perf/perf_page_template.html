Eden Planet Frame Budget

Six play scenarios on the V4 planet (eden_play.tscn) with the player character, each measured for 8 s after the terrain around the player has loaded. Vsync off, optimized editor binary.

How this was measured

Harness: python demo_eden/perf/run_perf_report.py bin/godot.windows.editor.x86_64.console.exe <out> 1920x1080 1280x720 1920x1080:passes, then python demo_eden/perf/perf_page.py <out>. The in-game side is demo_eden/perf/_perf_report.gd.

Each scenario: move the player (for the sea and equator), set the weather override, wait for ground collision plus 6 s, then record every frame for 8 s while the camera turns slowly. The pass breakdown comes from a separate run with --gpu-profile, since profiling adds a little overhead; its totals match the plain run within a few percent.
