2. **Standard Godot 4 Module Configuration**:
   - `config.py`: Implements `can_build()` (gated on `not disable_3d`), `configure()` (appends `GODOT_EDEN_ENABLED` define), `get_doc_classes()` (lists all 16 module classes), `get_doc_path()` (returns `"doc_classes"`).
   - `SCsub`: Clones `env_modules` into `env_godot_eden`, adds `#modules/godot_eden` to include path, compiles GLSL shaders via `RD_GLSL` (`micro_voxel_raymarch.glsl`, `clipmap_lod.glsl`), collects source files from all subdirectories.

   - `register_types.cpp`: Gates class registration with `p_level == MODULE_INITIALIZATION_LEVEL_SCENE`, registering all 16 classes with `GDREGISTER_CLASS(...)`.

3. **ClassDB Bindings & Inheritance Hierarchy**:
   - `VoxelWorld`: Inherits `Node3D`, macro `GDCLASS(VoxelWorld, Node3D)`. ClassDB properties: `voxel_volume`, `voxel_size`, `view_distance_chunks`, `enable_collision`. Bound methods: `update_world()`. Overrides `_notification()` for tree hooks (`NOTIFICATION_PROCESS`).
   - `VoxelVolume`: Inherits `Resource`, macro `GDCLASS(VoxelVolume, Resource)`. ClassDB properties: `chunk_size`, `max_lod_levels`, `volume_name`.
   - `VoxelRenderer` / `VoxelRendererRD`: Inherits `Node3D`, macro `GDCLASS(VoxelRendererRD, Node3D)`. Interacts directly with Vulkan `RenderingDevice`. Overrides `get_configuration_warnings()`.
   - `VoxelBuffer` (VoxelChunk): Inherits `RefCounted`, macro `GDCLASS(VoxelBuffer, RefCounted)`. 4096-element ($16^3$) storage supporting Uniform, Palette, and Raw modes. Binds channels (`CHANNEL_SDF`, `CHANNEL_MATERIAL`, `CHANNEL_COLOR`) and compression types (`COMPRESSION_UNIFORM`, `COMPRESSION_PALETTE`, `COMPRESSION_RAW`).
   - `VoxelStreamer` (VoxelStream): Inherits `RefCounted`, macro `GDCLASS(VoxelStreamer, RefCounted)`. Binds `set_view_center()`, `set_view_radius()`, `request_block()`. Supported by `VoxelStreamSQLite` and `VoxelStreamRegionFiles`.
   - `VoxelGenerator`: Inherits `Resource`, macro `GDCLASS(VoxelGenerator, Resource)`. Exposes `GDVIRTUAL1R(float, _generate_voxel, Vector3)` for GDScript overrideability. Extended by `VoxelGeneratorNoise` (FastNoise2 density field).
   - `AtcAttributePipeline` (VoxelMaterial): Inherits `RefCounted`, macro `GDCLASS(AtcAttributePipeline, RefCounted)`. Encodes octahedral 16-bit normals (`encode_normal_oct16`), packs GPU SSBO material palettes (`GpuMaterialData`).

4. **Engine Integration & Vulkan RenderingDevice**:
