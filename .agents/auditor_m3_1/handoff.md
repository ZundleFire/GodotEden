## 1. Observation

Direct static code analysis, execution tracing, and structural auditing were conducted across all 11 Milestone 3 deliverables:

1. **Vulkan GPU Compute Raymarcher (`modules/godot_eden/rendering/voxel_renderer_rd.h` and `.cpp`)**:
   - Class `VoxelRendererRD` inherits from `Node3D` (`voxel_renderer_rd.h:45`).
   - Interfacing methods `set_volume`, `set_svo_octree`, `set_data_map`, `set_atc_pipeline` trigger SSBO buffer uploads (`voxel_renderer_rd.cpp:61-83`).
   - Concentric LOD clipmap update loop `update_lod_clipmap()` (`voxel_renderer_rd.cpp:158-192`) computes snapped ring centers `floor(cam / scale) * scale`, toroidal grid cell offsets `grid_cell % clipmap_grid_extent`, and outer radius blend margins `outer_radius * 0.15f`.
   - `upload_svo_ssbo()`, `upload_clipmap_ssbo()`, `upload_material_palette_ssbo()` (`voxel_renderer_rd.cpp:194-258`) interface directly with Godot's `RenderingDevice` API (`rd->storage_buffer_create()`).
   - `dispatch_raymarch_compute()` (`voxel_renderer_rd.cpp:260-298`) and `dispatch_clipmap_compute()` (`voxel_renderer_rd.cpp:300-328`) construct push constant structs (`RaymarchPushConstants`, `ClipmapPushConstants`), calculate workgroup dimensions, and issue `rd->compute_list_dispatch()`.
   - Pipeline setup `_init_rd_pipelines()` (`voxel_renderer_rd.cpp:330-367`) dynamically loads SPIR-V headers (`MicroVoxelRaymarchShaderRD`, `ClipmapLodShaderRD`) generated by SCons.

2. **GLSL Compute Shaders (`modules/godot_eden/shaders/micro_voxel_raymarch.glsl` and `clipmap_lod.glsl`)**:
   - `micro_voxel_raymarch.glsl` implements stackless pointerless SVO DAG traversal using popcount octant indexing `bitCount(node.child_mask & ((1u << octant) - 1u))` (lines 160-167).
   - Material unpacking functions (`unpack_rgba8`, `unpack_oct16`, `unpack_rough_metal`, `unpack_rgb565`) decode std430 SSBO GPU material attributes (lines 53-83).
   - Ray-AABB intersection `ray_aabb_intersect()` and sphere-marching step calculation (lines 85-170).
   - `clipmap_lod.glsl` executes toroidal grid offset calculation and ring center snapping on GPU (lines 26-50).

3. **ATC Attribute & Material System (`modules/godot_eden/rendering/atc_attribute_pipeline.h` and `.cpp`)**:
   - `AtcAttributePipeline` inherits from `RefCounted` (`atc_attribute_pipeline.h:43`).
   - 16-bit octahedral normal encoding/decoding `encode_normal_oct16()` and `decode_normal_oct16()` implement octahedral sphere projection with $L_1$ normalization and lower-hemisphere folding (lines 77-112).
   - Bit packing methods `pack_rgba8()`, `pack_oct16()`, `pack_roughness_metallic()`, `pack_rgb565()` convert material attributes to std430 SSBO byte format (lines 234-266).
   - Central difference surface normal calculation `compute_surface_normal()` computes gradients over neighbor SDF voxels (lines 382-408).
   - Power-based triplanar weighting `calculate_triplanar_weights()` and linear ramp slope blending `calculate_slope_blend()` (lines 268-292).
   - Buffer conversion methods `convert_voxel_buffer_to_atc()` and `convert_attributes_to_packed_floats()` format raw voxel buffers into ATC data streams (lines 294-369).

4. **Physics Collision Mesh Generator (`modules/godot_eden/rendering/physics_mesh_generator.h` and `.cpp`)**:
   - `PhysicsMeshGenerator` inherits from `RefCounted` (`physics_mesh_generator.h:15`).
   - `generate_greedy_mesh_faces()` (`physics_mesh_generator.cpp:141-291`) implements 2D slice mask generation across all 3 primary axes and greedily merges adjacent quad regions along $u$ and $v$ dimensions, reducing a 4x4x4 cube from 96 quads to 6 consolidated quads (12 triangles / 36 vertices).
   - `generate_dual_contouring_faces()` (`physics_mesh_generator.cpp:346-444`) and `_get_dual_vertex_for_cell()` (lines 293-344) evaluate sign-changing crossings across 12 cell edges, perform linear zero-crossing interpolation `t = (iso - v0) / (v1 - v0)`, and construct dual contour quads.
   - `generate_data_map_collision_shape()` (lines 77-112) aggregates block meshes across `VoxelDataMap` regions into Godot `ConcavePolygonShape3D` collision hulls.

5. **Module Registration & SCons Integration (`register_types.cpp` and `SCsub`)**:
   - `register_types.cpp:40-42` registers `VoxelRendererRD`, `AtcAttributePipeline`, and `PhysicsMeshGenerator` with ClassDB at `MODULE_INITIALIZATION_LEVEL_SCENE`.
   - `SCsub:14-18` builds RD shader headers via `env_godot_eden.RD_GLSL()` for both compute shaders and compiles all `rendering/*.cpp` sources.

6. **Doctest Unit Test Suite (`tests/test_rendering.h`)**:
   - 338 lines of Doctest unit tests verifying ClassDB registration, property clamping bounds, octahedral normal roundtrips, attribute packing/unpacking, greedy mesh consolidation (36 vertices for 4x4x4 block), dual contouring sphere generation, and data map collision shape generation.
