# Technical Design & Specification: Micro-Voxel Renderer & Shaders Pipeline (Milestone 3)

## 1. Overview & Architecture

Milestone 3 of GodotEden introduces high-performance micro-voxel GPU compute raymarching using Godot 4's low-level `RenderingDevice` (RD) API. The pipeline consists of:
1. **`VoxelRendererRD` (`rendering/voxel_renderer_rd.h/cpp`)**: Node3D engine integration managing Vulkan `RenderingDevice` compute pipelines, SSBO buffers (SVO DAG pool, clipmap levels, ATC material palette), uniform sets, push constants, and compute dispatches.
2. **`AtcAttributePipeline` (`rendering/atc_attribute_pipeline.h/cpp`)**: Allocation-Tagging-Conversion voxel attribute pipeline for albedo colors, surface normal estimation, roughness, metallic, and material tags.
3. **`PhysicsMeshGenerator` (`rendering/physics_mesh_generator.h/cpp`)**: Dual contouring and greedy meshing generator constructing collision hulls (`ConcavePolygonShape3D`) for Godot physics.
4. **GLSL Compute Shaders (`shaders/micro_voxel_raymarch.glsl` & `shaders/clipmap_lod.glsl`)**: Vulkan GLSL compute shaders compiled automatically to C++ headers via SCons `glsl_builders.build_rd_headers`.

---

## 2. RenderingDevice (RD) Infrastructure & Pipeline Management

### 2.1 RenderingDevice Lifecycle in `VoxelRendererRD`
`VoxelRendererRD` communicates directly with Godot 4's `RenderingDevice` singleton retrieved via:
```cpp
RenderingDevice *rd = RenderingServer::get_singleton()->get_rendering_device();
```
When `rd` is `nullptr` (e.g. running in OpenGL compatibility mode or non-RD headless server), `VoxelRendererRD` gracefully disables compute raymarching without crashing.

### 2.2 Shader & Pipeline Creation
Shader headers generated by SCons `RD_GLSL` builder (`shaders/micro_voxel_raymarch.glsl.gen.h` and `shaders/clipmap_lod.glsl.gen.h`) export shader bytecode objects:
- `MicroVoxelRaymarchShaderRD::byte_code`
- `ClipmapLodShaderRD::byte_code`

RIDs and Compute Pipelines:
```cpp
RID raymarch_shader_rid = rd->shader_create_from_spirv(MicroVoxelRaymarchShaderRD::byte_code);
RID raymarch_pipeline_rid = rd->compute_pipeline_create(raymarch_shader_rid);

RID clipmap_shader_rid = rd->shader_create_from_spirv(ClipmapLodShaderRD::byte_code);
RID clipmap_pipeline_rid = rd->compute_pipeline_create(clipmap_shader_rid);
```

### 2.3 Storage Buffers (SSBOs)
`VoxelRendererRD` allocates and updates three Vulkan Storage Buffers (SSBOs):
1. **SVO DAG Storage Buffer (`svo_buffer_rid`)**:
   - Stores contiguous array of 16-byte aligned `SvoNode` structs from `LodOctree::get_ssbo_buffer_bytes()`.
   - Layout:
     ```cpp
     struct SvoNode {
         uint32_t child_mask;       // Bits 0-7: active child mask
         uint32_t first_child_idx;  // Index in pool of first contiguous child
         uint32_t material_tag;     // Material attribute ID
         float sdf_value;           // Distance value
     };
     ```
2. **Clipmap Level Storage Buffer (`clipmap_buffer_rid`)**:
   - Stores concentric LOD ring parameters. Size: `max_lod_levels * sizeof(ClipmapLevel)`.
   - Layout (32 bytes per level):
     ```cpp
     struct ClipmapLevelGpu {
         float center[3];
         float voxel_scale;
         int32_t grid_size[3];
         uint32_t lod_index;
     };
     ```
3. **Material Palette Storage Buffer (`palette_buffer_rid`)**:
   - Stores ATC material attributes (albedo, roughness, metallic, emissive).
   - Layout (32 bytes per material):
     ```cpp
     struct MaterialAttrGpu {
         float albedo[4];             // r, g, b, a
         float roughness_metallic[4]; // r: roughness, g: metallic, b: emissive, a: unused
     };
     ```

### 2.4 Uniform Set Construction
`VoxelRendererRD` creates uniform sets for Set 0:
- Binding 0: Output Target Image (`RD::UNIFORM_TYPE_IMAGE`)
- Binding 1: SVO SSBO (`RD::UNIFORM_TYPE_STORAGE_BUFFER`)
- Binding 2: Clipmap SSBO (`RD::UNIFORM_TYPE_STORAGE_BUFFER`)
- Binding 3: Palette SSBO (`RD::UNIFORM_TYPE_STORAGE_BUFFER`)

### 2.5 Push Constants
Push constant layout passed during `rd->compute_list_set_push_constant(...)`:
```cpp
struct RaymarchPushConstants {
    float camera_pos[3];
    float fov;
    float camera_dir[3];
    float max_distance;
    float screen_size[2];
    uint32_t max_lod_levels;
    uint32_t root_node_index;
};
```

## 4. GLSL Compute Shader Specifications

### 4.1 `shaders/micro_voxel_raymarch.glsl`
```glsl
#[compute]
#version 450

layout(local_size_x = 8, local_size_y = 8, local_size_z = 1) in;

layout(set = 0, binding = 0, rgba32f) uniform image2D out_color;

struct SvoNode {
	uint child_mask;       // Bits 0-7: active child mask
	uint first_child_idx;  // Index in pool of first contiguous child
	uint material_tag;     // Material attribute ID
	float sdf_value;       // Representative Signed Distance Function value
};

layout(set = 0, binding = 1, std430) buffer SvoBuffer {
	SvoNode nodes[];
} svo_dag;

struct ClipmapLevel {
	vec3 center;
	float voxel_scale;
	ivec3 grid_size;
	uint lod_index;
};

layout(set = 0, binding = 2, std430) buffer ClipmapBuffer {
	ClipmapLevel levels[];
} clipmap;

struct MaterialAttr {
	vec4 albedo_color;
	vec4 roughness_metallic_emissive;
};

layout(set = 0, binding = 3, std430) buffer MaterialPalette {
	MaterialAttr materials[];
} palette;

layout(push_constant) uniform PushConstants {
	vec3 camera_pos;
	float fov;
	vec3 camera_dir;
	float max_distance;
	vec2 screen_size;
	uint max_lod_levels;
	uint root_node_index;
} params;

bool raymarch_svo(vec3 ray_origin, vec3 ray_dir, out vec4 hit_color, out float hit_t) {
	float t = 0.0;
	float t_max = params.max_distance;
	uint curr_idx = params.root_node_index;

	for (int steps = 0; steps < 256; ++steps) {
		if (t >= t_max) break;
		vec3 pos = ray_origin + ray_dir * t;
		
		SvoNode node = svo_dag.nodes[curr_idx];
		if (node.child_mask == 0) {
			if (node.sdf_value <= 0.0 && node.material_tag > 0) {
				MaterialAttr mat = palette.materials[node.material_tag];
				vec3 norm = normalize(pos - floor(pos) - vec3(0.5));
				float light = max(dot(norm, normalize(vec3(0.5, 1.0, 0.3))), 0.2);
				hit_color = vec4(mat.albedo_color.rgb * light, 1.0);
				hit_t = t;
				return true;
			}
			t += max(abs(node.sdf_value), 0.1);
		} else {
			vec3 local_p = fract(pos);
			uint octant = (local_p.x > 0.5 ? 1 : 0) | (local_p.y > 0.5 ? 2 : 0) | (local_p.z > 0.5 ? 4 : 0);
			if ((node.child_mask & (1u << octant)) != 0u) {
				curr_idx = node.first_child_idx + octant;
			} else {
				t += 0.25;
				curr_idx = params.root_node_index;
			}
		}
	}
	return false;
}

void main() {
	ivec2 pixel_coords = ivec2(gl_GlobalInvocationID.xy);
	if (pixel_coords.x >= int(params.screen_size.x) || pixel_coords.y >= int(params.screen_size.y)) {
		return;
	}

	vec2 uv = (vec2(pixel_coords) + vec2(0.5)) / params.screen_size;
	vec2 ndc = uv * 2.0 - vec2(1.0);

	vec3 right = normalize(cross(params.camera_dir, vec3(0.0, 1.0, 0.0)));
	vec3 up = cross(right, params.camera_dir);
	vec3 ray_dir = normalize(params.camera_dir + right * ndc.x * params.fov + up * ndc.y * params.fov);
	vec3 ray_origin = params.camera_pos;

	vec4 hit_color;
	float hit_t;
	if (raymarch_svo(ray_origin, ray_dir, hit_color, hit_t)) {
		imageStore(out_color, pixel_coords, hit_color);
	} else {
		vec4 sky = vec4(mix(vec3(0.6, 0.8, 1.0), vec3(0.1, 0.2, 0.4), uv.y), 1.0);
		imageStore(out_color, pixel_coords, sky);
	}
}
```
